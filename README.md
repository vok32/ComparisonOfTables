# Инструмент для сравнения таблиц Excel

## Описание

Программа предназначена для сравнения старой и новой выгрузок Excel и автоматического поиска:

- новых строк;
- изменённых строк и ячеек;
- строк, которые были в старой таблице, но отсутствуют в новой;
- дополнительных столбцов, которые присутствуют только в старой таблице.

Результат сохраняется в отдельный Excel-файл с цветовой подсветкой изменений.

Программа ориентирована на таблицы, в которых одна и та же запись определяется сочетанием **ФИО + направление / конкурсная группа**. При необходимости номер договора можно использовать как дополнительный признак для более точного сопоставления строк.

---

## Основная логика сравнения

### ФИО + направление

Основным ключом сопоставления являются два столбца:

- **ФИО**;
- **Направление**.

В окне настройки сравнения программа пытается автоматически выбрать подходящие столбцы.

Для направления в первую очередь распознаётся столбец **«Конкурсная группа»**, затем варианты:

- «Направление»;
- «Направление подготовки»;
- «Специальность».

Для ФИО распознаются, в частности:

- «ФИО»;
- «Ф.И.О.»;
- «ФИО поступающего».

Выбранные значения при необходимости можно изменить вручную.

### Номер договора

Номер договора является дополнительным признаком сопоставления.

По умолчанию установлено:

**Номер договора → «— не использовать —»**

Если номер договора выбран:

- одинаковый заполненный номер имеет приоритет при сопоставлении;
- разные заполненные номера считаются разными записями;
- если в новой таблице номер договора пустой, это не мешает сопоставлению со старой строкой.

Если номер договора не выбран как отдельный признак, столбец при наличии всё равно остаётся обычным полем таблицы и участвует в оценке похожести строк.

### Дубли строк

Если у одного человека есть несколько записей с одинаковыми ФИО и направлением, программа ищет наиболее похожие пары строк по остальным общим столбцам.

Это позволяет корректнее обрабатывать ситуации, когда у одного человека несколько договоров или несколько записей внутри одной конкурсной группы.

---

## Игнорирование отдельных изменений

В окне **«Настройка сравнения»** можно отметить столбцы в разделе:

**«Не учитывать при определении изменений»**

Такие столбцы:

- продолжают участвовать в сопоставлении строк;
- не делают строку изменённой;
- не подсвечиваются как изменённые;
- в итоговый файл всё равно попадают со значением из новой таблицы.

Например, можно не учитывать изменение телефона или другого служебного поля, если оно не должно влиять на статус строки.

---

## Сравнение текстовых значений

При определении изменений текст сравнивается без учёта регистра.

Например:

- `ДА`
- `Да`
- `да`

считаются одинаковыми значениями.

---

## Дополнительные столбцы старой таблицы

Если в старой таблице есть столбцы, которых нет в новой, программа автоматически добавляет их в итоговый файл.

Для найденных строк значения этих столбцов переносятся из старой таблицы.

Для полностью новых строк такие поля остаются пустыми.

---

## Режимы сохранения

Программа поддерживает пять вариантов результата:

### Все строки

Сохраняются все строки новой таблицы:

- обычные строки;
- новые строки;
- изменённые строки.

### Новые строки

Сохраняются только строки, которых не было в старой таблице.

### Изменённые строки

Сохраняются только найденные строки, в которых изменилось хотя бы одно учитываемое поле.

### Новые + изменённые

Сохраняются:

- новые строки;
- изменённые строки.

Неизменённые строки в файл не попадают.

### Потеряшки

Сохраняются строки из старой таблицы, для которых не найдено соответствие в новой таблице.

---

## Цветовая подсветка

В итоговом Excel-файле используются следующие цвета:

- **жёлтый** — новая строка;
- **светло-зелёный** — изменённая строка;
- **зелёный** — конкретная изменённая ячейка;
- **красный** — строка из старой таблицы, отсутствующая в новой таблице в режиме «Потеряшки».

---

## Работа с итоговым файлом

По умолчанию результат сохраняется в папку:

`Desktop/Сравнение таблиц/differences.xlsx`

Если файл с таким именем уже существует, программа не перезаписывает его, а автоматически создаёт новую версию:

- `differences.xlsx`
- `differences_v2.xlsx`
- `differences_v3.xlsx`
- и т. д.

Имя итогового файла можно изменить в интерфейсе программы.

Пути в интерфейсе отображаются с обычными символами `/`.

---

## Поддерживаемые форматы

Программа поддерживает:

- `.xlsx`;
- `.xlsm`;
- `.xls`.

Для файлов `.xlsx` и `.xlsm` используется `openpyxl`.

Для старого формата `.xls` может потребоваться дополнительный пакет `xlrd`.

## Установка

### 1. Установите Python

Рекомендуется использовать актуальную версию Python 3.

### 2. Установите необходимые библиотеки

```bash
pip install pandas openpyxl
```

Для работы со старыми файлами `.xls` дополнительно:

```bash
pip install xlrd
```

`tkinter` обычно входит в стандартную поставку Python для Windows.

---

## Запуск

Сохраните программу, например, под именем:

`comp_tabl_win_release.py`

Запустите её командой:

```bash
python comp_tabl_win_release.py
```

---

## Порядок работы

1. Выберите **первый файл** — старую / исходную таблицу.
2. Выберите **второй файл** — новую таблицу.
3. Укажите папку и имя файла для сохранения результата.
4. Выберите режим:
   - «Все строки»;
   - «Новые строки»;
   - «Измененные строки»;
   - «Новые + изменённые»;
   - «Потеряшки».
5. Нажмите **«Далее»**.
6. В окне настройки проверьте столбцы:
   - ФИО;
   - направление;
   - номер договора.
7. При необходимости отметьте столбцы, изменения которых не нужно учитывать.
8. Нажмите **«Создать файл»**.
9. После завершения программа покажет путь к сохранённому файлу.
10. При необходимости нажмите **«Открыть папку с файлом»**.

---

## Важные условия

Для надёжного сопоставления строк:

- ФИО должно быть заполнено;
- направление / конкурсная группа должно быть заполнено;
- выбранные столбцы ФИО и направления должны быть разными;
- если номер договора используется как дополнительный признак, он не должен совпадать со столбцами ФИО или направления.

Если обязательные значения отсутствуют, программа покажет понятное сообщение об ошибке и не начнёт некорректное сравнение.

## Интерфейс

В программе доступны:

- выбор исходных Excel-файлов;
- выбор места сохранения;
- изменение имени итогового файла;
- выбор режима сохранения;
- настройка столбцов сопоставления;
- исключение отдельных столбцов из определения изменений;
- окно информации о приложении;
- окно информации о разработчике;
- кнопка открытия папки с готовым результатом.
